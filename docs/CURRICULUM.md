## 0. Prinsip Desain (Non-Negotiable)

1. **Pemahaman > Hafalan.** Setiap kata/frasa selalu disertai konteks situasi. User ga sekedar "tahu artinya" tapi "tahu kapan dipakai".
2. **Hijazi-first, bukan Fusha.** Dialek Saudi praktis (yang dipakai di pasar Madinah, hotel di Mekkah, sopir bus umrah). Fusha hanya untuk modul religious/akademik.
3. **Snackable, bukan akademik.** Target 1 lesson = **5-7 menit**, bisa diselesaikan di sela waktu (di bus, antri makan). Bukan 30-menit kuliah.
4. **Audio dulu, baca kedua.** Untuk jamaah umrah, **mendengar dan berbicara** jauh lebih kritikal daripada baca tulisan Arab. Vocabularinya dengan transliterasi Latin selalu.
5. **Reward kecil & sering.** XP per micro-action (vocab learned, dialog completed, quiz score). Bukan reward besar di akhir lesson saja.

## 1. Level System

Disederhanakan dari CEFR — sesuai konteks jamaah umrah & wisatawan:

| Level | Nama Internal | Kemampuan Pengguna | Estimasi Pencapaian |
|-------|---------------|--------------------|--------------------:|
| **🌱 Mubtadi** | Pemula Sekali | Salam, terima kasih, ya/tidak, angka 1-10 | Hari 1-3 |
| **🌿 Daris** | Pelajar Awal | Survive transaksi sehari-hari (belanja, makan, hotel) | Minggu 1-2 |
| **🌳 Mutawassith** | Menengah | Bisa minta tolong, jelaskan masalah, ngobrol singkat | Bulan 1-2 |
| **🌲 Faaheem** | Paham (lanjutan) | Diskusi topik sederhana, baca menu/papan info | Bulan 3-6 |
| **⭐ Mahir** | Mahir | Percakapan natural, tidak panik di situasi tak terduga | 6+ bulan |

**Target v1.0 (3 bulan pertama):** User selesai Mubtadi + Daris untuk path **Umrah**. Cukup buat survive 10 hari trip.

## 2. 3 Paths — Detail Modul

### 🕌 Path A: Wisatawan & Jamaah Umrah (PRIORITAS v1.0)

Target: jamaah umrah Indonesia, durasi pakai 1-3 bulan sebelum keberangkatan.

**Modul Mubtadi (level pemula sekali) — 5 lesson @ 5 menit:**

1. **Salam & Sapaan** (existing — perlu di-deepen)
   - As-salamu 'alaikum, Marhaban, Sabahul khair
   - Cara balas, kapan dipakai
2. **Perkenalan Diri**
   - Ismi... (nama saya), min Indunisiya (dari Indonesia), ana hajji/mu'tamir
3. **Terima Kasih & Maaf**
   - Shukran, afwan, lā ba's
4. **Angka 1-10 + Mata Uang Riyal**
   - Wahid, ithnan, ... 'asyrah
   - Riyal, halalah, kam sa'r? (berapa harga)
5. **Ya/Tidak/Mungkin & Frasa Darurat**
   - Na'am, lā, mumkin, sa'idnī (tolong saya)

**Modul Daris (pelajar awal) — 10 lesson @ 5-7 menit:**

6. **Tanya Arah ke Masjid Nabawi/Haram**
   - Wayn al-Haram? Hadhihi al-thariq? (Apakah jalan ini?)
7. **Makan di Restoran Pasar**
   - Bikam? Hadha lazheez (ini enak), bidūn sukar (tanpa gula)
8. **Belanja Oleh-Oleh** (existing Pasar Madinah, perlu di-deepen)
   - Kam ar-riyal? Aqal (lebih murah dong), khudh (ambil ini)
9. **Hotel & Akomodasi**
   - Wayn al-miftah? (kunci di mana), al-wifi, al-hammaam (kamar mandi)
10. **Transportasi (Bus, Taksi)**
    - Bikam ila Mekkah? Ya astaz (pak/mas), tawaqaf hena (berhenti di sini)
11. **Sakit & Darurat**
    - Ana ta'baan (saya capek), wayn al-mustasyfa (RS), 'andi alam (saya sakit)
12. **Sholat & Masjid**
    - Wayn al-mihrab? Wayn dawrat al-miyah (toilet)? Imamah?
13. **Telepon & Kontak**
    - Raqm jawalik (no HP-mu), WA, ittasil bi (hubungi)
14. **Cuaca & Waktu**
    - Hār (panas), bārid (dingin), as-sa'ah kam (jam berapa)
15. **Kembali ke Indonesia / Salam Pisah**
    - Ila al-liqā', barakallahu fīk, 'aja'tum bil khair

**Modul Mutawassith — 10 lesson @ 7-10 menit** (post-launch):
- Pasar tradisional dengan tawar-menawar
- Berbicara dengan ustadz di majelis
- Bertanya tentang tempat ziarah
- Sosial dengan jamaah lain
- ...

## 3. Anatomi 1 Lesson (Format Standar)

**Durasi:** 5-7 menit
**XP reward total:** 50-80 XP per lesson (perfect)

```
┌─ STAGE 1: PENGANTAR (15 detik) ───────────────┐
│ Hook: "Bayangkan kamu lagi di pasar Tamr..." │
│ + Visual ilustrasi suasana                   │
│ Tombol: Mulai                                │
└───────────────────────────────────────────────┘

┌─ STAGE 2: KOSAKATA INTI (1-2 menit) ──────────┐
│ 5-7 vocab cards:                             │
│   - Tulisan Arab (Reem Kufi font)            │
│   - Transliterasi Latin                      │
│   - Arti Indonesia                           │
│   - Audio play button (Web Speech ar-SA)     │
│   - Optional: gambar/emoji                   │
│ User tap "Sudah paham" → +5 XP per vocab     │
└───────────────────────────────────────────────┘

┌─ STAGE 3: DENGAR & TIRUKAN (1 menit) ─────────┐
│ Setiap vocab di-play 2× berturut             │
│ Tombol mic (rekam diri ngucap)               │
│ → Phase 2: speech recognition feedback       │
│ → Phase 1 (sekarang): self-rated checkmark   │
│ +10 XP                                       │
└───────────────────────────────────────────────┘

┌─ STAGE 4: DIALOG MINI (1-2 menit) ────────────┐
│ Skenario 4-6 baris dialog:                   │
│   "🧕 Jamaah: As-salamu 'alaikum"            │
│   "👳 Penjual: Wa 'alaikum salam!"           │
│   "🧕 Jamaah: Kam sa'r al-tamr?"             │
│   "👳 Penjual: 'Asyrah riyal"                │
│   ... dst                                    │
│ Audio play satu-satu, atau full              │
│ +15 XP                                       │
└───────────────────────────────────────────────┘

┌─ STAGE 5: LATIHAN INTERAKTIF (1 menit) ───────┐
│ 3-5 micro-exercises, salah satu dari:        │
│   - Tap arti yang benar (MCQ)                │
│   - Susun kalimat (drag-drop)                │
│   - Isi kata yang hilang                     │
│   - Cocokkan Arab ↔ Indonesia                │
│ +5 XP per benar                              │
└───────────────────────────────────────────────┘

┌─ STAGE 6: QUIZ FINAL (1 menit) ───────────────┐
│ 5 soal cepat, 10 detik per soal              │
│ Score-based XP: skor × 6 (+10 bonus perfect) │
└───────────────────────────────────────────────┘

┌─ STAGE 7: TIPS BUDAYA + UNLOCK (30 detik) ────┐
│ "Tahukah kamu? Pedagang Madinah biasanya     │
│ kasih diskon kalau kamu tanya pakai 'min     │
│ fadhlik' (tolong) dengan senyum 😊"          │
│ + Badge progress unlock                      │
└───────────────────────────────────────────────┘
```

**XP per lesson breakdown:**
- 5 vocab × 5 XP = 25
- Dengar & Tirukan: 10
- Dialog: 15
- Latihan: 15-25
- Quiz: 0-40 (skor)
- **Total possible: 65-115 XP per lesson**

## 5. Audio Strategy (Phased)

### Phase 1 — Web Speech API (SEKARANG)
- Native browser TTS dengan locale `ar-SA`
- Pro: Free, no recording, semua text bisa di-baca otomatis
- Con: Robot voice, dialek standar (bukan Hijazi pure)
- Status: Belum dipasang, **prioritas implementasi pertama untuk fix audio bug**

```javascript
const playAudio = (arabicText) => {
  const utterance = new SpeechSynthesisUtterance(arabicText);
  utterance.lang = 'ar-SA';
  utterance.rate = 0.8;  // pelan biar jelas
  speechSynthesis.speak(utterance);
};
```

### Phase 2 — Hybrid (3-6 bulan)
- Top 100 frasa paling penting: recording native speaker
- Sisanya: TTS
- Mukim Partner / mahasiswa Indonesia Madinah bisa jadi voice talent

### Phase 3 — Full Native (6-12 bulan)
- Semua audio native recording
- Multiple voices (pria, wanita, anak)
- Variasi dialek (Hijazi murni, Najdi, Khaliji)

## 6. Spaced Repetition (Phase 2 feature)

Belum di v1, tapi data model udah siap (`vocabLearned: [vocab_ids]`).

Sistem:
- Vocab yang user pelajari masuk pool review

- "Review Hari Ini" widget di home screen
- Forget-curve algorithm sederhana (kalau salah → reset interval, kalau benar → kalikan)

## 9. Risks & Mitigations

| Risk | Mitigation |
|------|------------|
| Konten Hijazi salah / ofensif | Native speaker validator wajib (1-2 orang) |
| Audio TTS suara robot, user kecewa | Disclaimer "audio dasar, suara native menyusul"; recording top 100 frasa di Bulan 2 |
| 100+ lesson terlalu banyak buat 1 founder | AI-assisted draft (saya bisa bantu), native validator, fase-fase |
| User bingung mulai dari mana | Onboarding tour yang assign path otomatis berdasarkan interest |
| Konten musiman (Ramadhan, Haji) | Dedicated event module yang muncul otomatis berdasarkan tanggal Hijriah |
